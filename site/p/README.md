# `/p/` カテゴリランキング記事（テンプレート）

楽天カテゴリ寄りの通販整理記事。番組の総合1位ページではない。

task_id: `web-rakuten-category-rank-pilot-20260919`

## URL

| 種類 | パス | 例 |
|---|---|---|
| ハブ | `/p/` | カテゴリ記事の入口 |
| カテゴリランキング | `/p/<category-slug>/` | `/p/ketchup/` |
| 商品購入ガイド（既存） | `/p/<product-slug>/` | `/p/sunsun-sponge-black/` |

`/satapla/<theme>/` は放送回横断の番組まとめ（独自ランキングを作らない）。カテゴリの売れ筋整理は `/p/<category-slug>/` に置く。

## パイロット

1本だけ: [`/p/ketchup/`](ketchup/)（ケチャップ）。既存アフィリンクが最も多い食・キッチン日用品。

## 必須構成

1. `hero-kicker`: 通販ガイド（放送日や「サタプラ総合1位」をページ枠にしない）
2. H1: `<カテゴリ>おすすめ／売れ筋`
3. 方法論を本文で明示する。ライブの楽天公式総合ランキングを取れないときは、**当サイト掲載の通販候補**を楽天側の信号（レビュー件数・評価・価格帯）で並べ、次の文言を置く。

   > 当サイト掲載の通販候補をもとに整理（楽天公式総合ランキングの複製ではない）

4. 「楽天1位」は公式根拠がない限り書かない
5. 商品ごとに用途・選び方・注意。FAQを置く
6. アフィはリポジトリに実在する URL、または確認できた URL だけ。捏造しない
7. 「テレビでも紹介された商品」は任意の二次枠。ページの背骨にしない
8. 買いあと導線（ポスト型 CTA）。本文に「今わかっていること」や運用手順を置かない
9. 新規 URL は `sitemap.xml` に追加。ハブ `/p/` からリンクする

次のカテゴリを足すときは、このファイルの必須構成をコピーし、`site/p/<slug>/index.html` を1本追加してハブと sitemap だけ更新する。
