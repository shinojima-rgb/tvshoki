## 必須構成

放送後の「テレビで出たものも良いけど、他も検討したい」がページの背骨。

1. `hero-kicker`: 通販ガイド（放送日や「サタプラ総合1位」をページ枠にしない）
2. H1: `<カテゴリ>おすすめ／売れ筋`
3. **先に** `#tv-onair`「放送で出たもの」— そのカテゴリで当サイトに既にあるテレビ紹介SKU（信頼の入口）
4. **すぐ下に** `#compare`「同じカテゴリのほかの候補」— 楽天側の信号（レビュー件数・評価・価格帯）。商品ごとに用途・選び方・注意
5. 番組順位と楽天の並びは別物、と本文で明示する。ライブの楽天公式総合ランキングを取れないときは次の文言を置く。

   > 当サイト掲載の通販候補をもとに整理（楽天公式総合ランキングの複製ではない）

6. 「楽天1位」は公式根拠がない限り書かない。TV順位＝楽天順位とも書かない
7. アフィはリポジトリに実在する URL、または確認できた URL だけ。捏造しない
8. 買いあと導線（ポスト型 CTA）。本文に「今わかっていること」や運用手順を置かない
9. 新規 URL は `sitemap.xml` に追加。ハブ `/p/` からリンクする
10. 放送回ページから「他も見る」で `#compare` に深リンクできる（任意・破壊しない関連リンクのみ）

次のカテゴリを足すときは、このファイルの必須構成をコピーし、`site/p/<slug>/index.html` を1本追加してハブと sitemap だけ更新する。
